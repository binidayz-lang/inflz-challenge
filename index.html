Firebase 설정이 필요해요

아래 4단계를 따라하면 수강생 데이터가
클라우드에 저장돼요 (약 10분 소요)

1

Firebase 프로젝트 만들기

구글 계정으로 접속 → "프로젝트 추가"
console.firebase.google.com

2

웹 앱 등록 → config 복사

프로젝트 홈 → ⚙️ → "앱 추가" → </> 웹 → 앱 이름 입력 → 등록
firebaseConfig 코드 블록 복사

3

Realtime Database 활성화

왼쪽 메뉴 → 빌드 → Realtime Database → "데이터베이스 만들기" → 테스트 모드로 시작

4

이 파일 상단 FIREBASE_CONFIG 수정

복사한 config를 아래 위치에 붙여넣기 후 Netlify에 다시 배포

const FIREBASE_CONFIG = { apiKey: "복사한값", authDomain: "복사한값", databaseURL: "복사한값", projectId: "복사한값", storageBucket: "복사한값", messagingSenderId: "복사한값", appId: "복사한값" };
설정 완료 후 파일을 Netlify에 다시 드래그하면 바로 작동해요 😊
